Запуск (Windows)
  1. Распакуйте файлы в одну папку.
  2. Запустите start-local-server.ps1 (правый клик → «Выполнить с помощью PowerShell»).
  3. Откроется http://127.0.0.1:8765/. Для остановки нажмите Ctrl+C в окне PowerShell.

Сеть не используется приложением после запуска; все учебные данные и прогресс остаются в браузере.
Если открыть index.html двойным щелчком, браузер предложит один раз выбрать vocabulary.json.

Прогресс сохраняется в localStorage этого браузера и профиля пользователя. Очистка данных сайта удалит прогресс.
Время обучения учитывается только во время открытой вкладки и занятий.

Состав словаря
  Английские подсказки и нумерация извлечены из предоставленного TOPIK-I-1671.pdf.
Русские переводы первоначально подготовлены автоматическим переводом английских подсказок из исходного PDF. При последующей проверке исправлены выявленные контекстные ошибки (в том числе 가깝다, 가볍다, 밝다, 감기, 닫다, 듣다, 아프다, 잃다 и другие); основные значения неоднозначных слов, включая 걸리다, дополнены вручную. Полная редакторская вычитка всех 1670 записей ещё не завершена, поэтому отдельные ошибки могут сохраняться.
Для части слов часть речи сопоставлена со словарём Korean Basic Dictionary Национального института корейского языка через набор данных Korwid.
Источник части речи: https://krdict.korean.go.kr · атрибуция набора Korwid: https://www.korwid.com/licenses
Условия для производных данных о части речи: CC BY-SA 2.0 KR, https://creativecommons.org/licenses/by-sa/2.0/kr/ . Изменение: переведены метки частей речи на русский и сопоставлены с заголовками PDF.
Большинство корейских примеров и русских переводов примеров были сгенерированы автоматически. Явно неестественные и ошибочные примеры, замеченные при проверке, исправлены; весь набор примеров также требует отдельной вычитки.
Для выбранных примеров использованы и адаптированы словарные контексты Korean Basic Dictionary Национального института корейского языка: https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=70709&nation=eng , https://krdict.korean.go.kr/spa/dicSearch/SearchView?ParaWordNo=46944&nation=spa , https://krdict.korean.go.kr/m/eng/searchResultView?ParaWordNo=15689 . Эти материалы распространяются по CC BY-SA; адаптированные записи помечены полем exampleSource.

Дубликат 처음 удалён по корейскому заголовку: PDF содержит 1671 строку и 1670 уникальных заголовков. Уроки распределены равномерно на 50 групп по 33–34 слова.
В приложении нет внешних библиотек и CDN-зависимостей. Озвучивание использует SpeechSynthesis API браузера.

Обновлённая логика урока
  Просмотр слова сам по себе не засчитывается как успешное вспоминание.
  Карточки, практика и написание охватывают все слова урока; ошибочные слова возвращаются в следующем круге.
  Этап не завершается, пока на каждое слово не дан правильный ответ.
  Практика содержит только тесты на выбор слова и задания с пропуском; у каждого вопроса четыре разных варианта. Свободный ввод и сборка слогов доступны только на этапе написания.
  В проверке написания можно переключаться между вводом корейского текста и сборкой слова из перемешанных слоговых блоков.
  В этапе чтения выделено предложение, к которому относится текущий вопрос; варианты ответа — переводы предложений из того же мини-текста и не меняют порядок после ответа.
  Незавершённый урок, этап, позиция слова и ответы текущего круга сохраняются в localStorage и восстанавливаются при следующем открытии.
